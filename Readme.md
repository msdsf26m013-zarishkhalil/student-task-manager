# Student Task Manager

## Project Description

Student Task Manager is a simple web-based application designed to help students manage their academic tasks. The project allows users to enter task titles and descriptions and provides a clean and organized interface for managing tasks.

This project was developed as part of a Git and GitHub collaborative assignment to demonstrate version control, branching, collaboration, code review, pull requests, merge conflicts, GitHub Issues, and other Git/GitHub features.

## Git Workflow

The project follows a feature-branch workflow.

1. Create or modify a feature on a separate branch.
2. Check changes using `git status` and `git diff`.
3. Stage changes using `git add`.
4. Commit changes using a meaningful commit message.
5. Push the feature branch to GitHub.
6. Create a Pull Request.
7. Review the Pull Request.
8. Approve the Pull Request after review.
9. Merge the Pull Request into `main`.
10. Pull the latest changes to keep local repositories synchronized.

### Workflow

```text
Working Directory
       ↓
Staging Area
       ↓
Local Repository
       ↓
Feature Branch
       ↓
GitHub Remote Repository
       ↓
Pull Request
       ↓
Code Review
       ↓
main
```

## How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/msdsf26m013-zarishkhalil/student-task-manager.git
```

### 2. Open the Project Directory

```bash
cd student-task-manager
```

### 3. Open the Application

Open `index.html` in a web browser.

Alternatively, the project can be opened in Visual Studio Code and run using a browser or a Live Server extension.
